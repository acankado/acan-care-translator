# 介護向け日本語方言・多言語翻訳アプリ（試用版）

日本語の方言を標準語に置き換え、ベトナム語・ミャンマー語・インドネシア語・タガログ語・英語へ翻訳する試作アプリです。

## 試用方法
GitHub Pages を有効にした後、公開URLへアクセスしてください。テキストを入力（またはOSの音声入力機能で入力）し、標準語変換、翻訳を試せます。

## 現在の仕様と制限
- HTML/CSS/JavaScriptで構成された静的ページであり、ビルド不要です。
- 方言変換は登録された表現のルールベース置換です。すべての方言や文脈を理解するものではありません。
- 音声認識はアプリ独自のエンジンではなく、端末・OSの音声入力機能に依存します。
- 外国語翻訳時は MyMemory の外部APIに入力文章が送信されます。利用回数制限やサービス側の制限により翻訳できない場合があります。
- 音声読み上げは端末・ブラウザの音声合成機能に依存します。

## 試用時の注意（重要）
- **実際の利用者の氏名、病状、介護記録、その他の個人情報や機密情報を入力しないでください。** 架空の例文・模擬会話で試してください。
- 服薬、移乗、転倒、急変など安全性に関わる判断に翻訳出力を単独で使用しないでください。
- 公開GitHub Pagesは一般公開URLになります。URLを知っている人だけにアクセスを制限する仕組みではありません。
- 医療・介護現場での本番運用前に翻訳精度・セキュリティ・情報保護の確認が必要です。
